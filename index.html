About

Quality assurance with curiosity and care.

I enjoy the process of understanding how an application is meant to behave, looking for the edge cases that might be missed, and creating useful test coverage that helps teams release with confidence.

My experience includes manual, functional, regression, exploratory, usability, UI automation, and API testing. I especially value test cases and bug reports that are clear enough for others to act on quickly and confidently.

Away from software, I enjoy supporting children’s learning and enrichment, designing educational materials, planning family adventures, and experimenting with creative projects like soap making.
